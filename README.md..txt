 HR Analytics Dashboard — Employee Insights & Attrition Analysis

 Project Overview
This project explores employee attrition, retention, and workforce patterns using the IBM HR Analytics Employee Attrition & Performance dataset.

 Tools Used
- Power BI
- Power Query
- DAX
- SQL
- Excel

 Key Analysis
- Total employees and employees who left
- Attrition and retention rates
- Attrition by department and job role
- Overtime and job satisfaction
- Age groups and years at the company

See the `screenshots` folder for the dashboard preview.

 Dataset
IBM HR Analytics Employee Attrition & Performance dataset from Kaggle.
